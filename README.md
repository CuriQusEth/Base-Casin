# Base Casino

Welcome to **Base Casino**, a flashy, mobile-first, web3-enabled crypto casino simulator deployed on the Base Mainnet!

## Features

- **Lucky Spin (Slots):** High-volatility slot machine with Base-themed symbols and win streaks.
- **Rocket Crash:** Classic crash game where players ride the multiplier to the moon and try to cash out before the inevitable crash.
- **ERC-8004 Active AI Agent:** Comes fully equipped with the **Base Casin Orchestrator**, an autonomous AI agent capable of multi-game orchestration, betting management, and risk automation via the Model Context Protocol (MCP).
- **Web3 Integration:** Fully integrated with Base Mainnet, wagmi configs, and simulated on-chain game logging to handle smart contract actions (ERC-8021).
- **Vault & Rewards:** Seamlessly bridge in-game chips to theoretical on-chain tokens.

## Getting Started

1. Clone or download the repository.
2. Run \`npm install\` to grab all dependencies.
3. Run \`npm run dev\` to launch the application locally.

## Built With

- React (Vite)
- Tailwind CSS
- Framer Motion
- Wagmi + Viem
- Express.js (for bridging standard REST API routes for MCP)
